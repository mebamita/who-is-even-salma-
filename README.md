# who-is-even-salma-
This is my personal portafolio, but this time done well. I started learning web design some months ago, so I thought this would be nice. For this project, I used CSS and Javascript, and tried to make a little introduction to who I am (with an emphasis in technology, since I'm sending this project for review in Macondo--Hack Club), trying to include a .pdf of my CV, and demos/videos of my last projects. This is yet just the MVP (Minimun Viable Product), because it yet doesn't include:
1) A section for MUN (since it's very important for me)
2) A responsive mechanism for phones and tablets (it can adjust to a computer's screen size, though).

I drew both the background and the characters (again, once I update it, I'll most likely add more, since I already have the characters designed), and looked in Codepen.io for a formula that I could adapt to make the entrance animation.

It's pretty much obvious now, but since I was just starting web design, I used to write HTML, CSS and Javascript in the same file, and now that I do it in different ones, everything is so much more organized and easier to read altogether. As well, I decided to make very simple animations with Javascript, just to experiment, since in last projects I tried many libraries and wasn't able to execute them properly. I tried to use Animate.css, but it only worked for entrance animations, I had tried to use Hover.css, Flyon UI, etc etc, but after an exhaustive research, I just decided to make everything with Javascript (which, surprisingly, has been much easier for me).
