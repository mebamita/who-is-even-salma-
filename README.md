# who-is-even-salma-
This is my personal portafolio, but this time done well. I started learning web design some months ago, so I thought this would be nice. For this project, I used CSS and Javascript, and tried to make a little introduction to who I am (with an emphasis in technology, since I'm sending this project for review in Macondo--Hack Club), trying to include a .pdf of my CV, and demos/videos of my last projects. This is yet just the MVP (Minimun Viable Product), because it yet doesn't include:

1) A responsive mechanism for phones and tablets (it can adjust to a computer's screen size, though).
2) More pictures + Cursor configuration (which is super short).
3) A link for Flappy Hitori's demo.

Those are things that I'm currently trying to fix.

I drew both the background and the characters, and looked in Codepen.io for a formula that I could adapt to make the entrance animation. It's pretty much obvious now, but since I was just starting web design, I used to write HTML, CSS and Javascript in the same file, and now that I do it in different ones, everything is so much more organized and easier to read altogether. As well, I decided to make very simple animations with Javascript, just to experiment, since in last projects I tried many libraries and wasn't able to execute them properly. I tried to use Animate.css, but it only worked for entrance animations, I had tried to use Hover.css, Flyon UI, etc etc, but after exhaustive research, I just decided to make everything with Javascript (which, surprisingly, has been much easier for me). I also had this huge problem, in which I cloned my local file, and accidentally erased the original one (the one I'm using to track my time in Hackatime), so I had been working on the cloned file for a while without noticing.

Still, I'm pretty much proud of how this turned out for now, and I think I learned a lot while making it (now I have a new div for everything).
